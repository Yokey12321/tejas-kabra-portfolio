# Tejas Kabra — Electrical Engineering Portfolio

An engineering case-study portfolio built with Astro, React, TypeScript, Tailwind CSS, Motion for React, and MDX.

## Commands

```sh
npm install
npm run dev
npm run check
npm run build
```

Project case studies live in `src/content/projects`. Images should be imported through Astro's asset pipeline from `src/assets/projects`.
