## System overview

Texas A&M RoboMasters needed a compact embedded platform for robot subsystems. The goal was to avoid rebuilding the same power, communication, sensing, and programming circuitry for each prototype.

I designed a custom STM32H7-based development board that combines those functions into one controller. The board supports subsystem bring-up, debugging, and integration with the team's mechanical and software systems.

## Board architecture

The power tree uses a 24 V-to-5 V buck stage followed by a 5 V-to-3.3 V LDO. These rails support the microcontroller, onboard sensing, and external interfaces while matching the robot's available supply.

The STM32H7 is supported by an external crystal oscillator, SWD programming and debugging access, CAN and UART connectivity, multifunction GPIO expansion, and an onboard LSM6DSO32R inertial measurement unit.

> Design goal: keep power, communications, sensing, and debug access usable after the board is installed on a robot.

### Design scope

- 24 V-to-5 V buck regulation
- 5 V-to-3.3 V LDO regulation
- STM32H7 core, decoupling, reset, and crystal oscillator
- LSM6DSO32R six-axis IMU
- CAN and UART communication
- SWD programming and external debug access
- Multifunction GPIO expansion

## Altium library and layout work

I created custom Altium component footprints for parts that were not already available in the team library and laid out the board around electrical function and subsystem access. I also supported development of a CAN breakout board used elsewhere in the robot architecture.
