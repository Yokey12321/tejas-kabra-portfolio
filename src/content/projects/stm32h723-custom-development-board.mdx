## A reusable controller for robot subsystems

Texas A&M RoboMasters needed a compact embedded platform that could control robot subsystems without rebuilding the same power, communication, sensing, and programming circuitry for every prototype.

I designed a custom STM32H7-based development board that integrates those functions into one reusable controller. The board supports subsystem bring-up, hands-on debugging, and integration with the team’s mechanical and software systems.

## Board architecture

The power tree uses a 24 V-to-5 V buck stage followed by a 5 V-to-3.3 V LDO. This provides the rails required by the microcontroller, onboard sensing, and external interfaces while matching the robot’s available supply.

The STM32H7 is supported by an external crystal oscillator, SWD programming and debugging access, CAN and UART connectivity, multifunction GPIO expansion, and an onboard LSM6DSO32R inertial measurement unit.

> The board was designed as an integration tool: power, communications, sensing, and debug access all needed to remain usable once installed on a robot.

### Design scope

- 24 V-to-5 V buck regulation
- 5 V-to-3.3 V LDO regulation
- STM32H7 core, decoupling, reset, and crystal oscillator
- LSM6DSO32R six-axis IMU
- CAN and UART communication
- SWD programming and external debug access
- Multifunction GPIO expansion

## Altium library and layout work

I created custom Altium component footprints for parts not already available in the team library and laid out the board around electrical function and subsystem access. I also supported development of a CAN breakout board used elsewhere in the robot architecture.
