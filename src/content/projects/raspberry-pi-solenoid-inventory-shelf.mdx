## System overview

Electrical components were organized physically, but team members still had to search bins manually and track access separately. Built an automated inventory system that connects authenticated digital checkout to electromechanical access at the shelf.

The system uses a Raspberry Pi, a Python touchscreen application, card-based authentication, I2C-controlled solenoid driver boards, and mechanical actuators.

## System architecture

The Raspberry Pi owns the user interface, authentication, checkout state, and command logic. Python software maps each inventory selection to an output on the I2C-connected driver network. The driver boards then switch the solenoids that control physical access to the organized components.

This separation keeps the Pi on the logic side of the system while dedicated hardware handles the current and electromechanical behavior of the actuators.

> The system connects user authentication, component selection, and physical access control.

## Integration and debugging

Integrated and debugged GPIO and I2C communication, solenoid actuation, power delivery, and driver-board behavior. Repeated mechanical operation exposed issues that do not appear in software-only testing, so reliability depended on validating the complete electrical and mechanical chain.
